# 女娲 1.48 写作模块

根据用户提供的《【写卡专用】女娲1.48.json》整理。模块可按名字单独调用。

| 模块 | 用法 |
| --- | --- |
| 造人 | 围绕一句核心概念展开。写可观察的外貌与气质、人格形成经历、价值排序、显性目标与内在冲突、行为与语言、重要关系和稳定底线。用能影响选择的细节，保留情境差异。 |
| 泥胎 | 用较少篇幅保留身份、驱动、行为和关系。区分能力、经验与意愿。让叙事原型辅助角色辨识，具体经历和选择优先。 |
| 迁徙 | 做同人卡时对齐用户选定的原作、时间线或 AU。区分原作事实与二创补写，必要时确定哪版为准。 |
| 创世 | 背景、地点、规则、势力、道具、伏笔按触发需要拆条。条目正文写明主体与事实，可独立理解。专有名与常见别名做关键词。常驻只用于广泛影响剧情的前提或规则。复杂世界按需要增加世界观与 NPC 条目，无需固定数量。 |
| 众生 | 为相关 NPC 写身份、可辨认的行为或口吻、动机和与其他人物的联系；配角有自己的目标。仅承担道具功能的角色可简写。 |
| 抟土 | 需要玩家专属身份时，在世界和主角关系明确后提供可选身份。写身份、初始处境、与角色的连接和切入点，把性格、行动和感受留给玩家决定。 |
| 过往 | 选择能解释人物现状的过去事件，核对参与者和时间线。可整理进人设或世界书，依据故事需求决定是否用已选文风写成独立片段。 |
| 文心 | 把风格化为可执行约束，例如视角、句长、叙事距离、对白、感官和意象，写清想保留及规避的特征。可借用户指定作品讨论手法。运行时指导可用一条短常驻世界书条目。 |
| 肇始 | 让主角用行动和对白亮相，场面自然体现规则或关系。在具体的抉择、变故或邀请处交棒，留一个可追问的伏笔。默认保留玩家行动权。篇幅、视角和节奏随风格与用户偏好，长篇氛围版可用预设的 6–10 段。每个备选开局应有自己的切入点。 |
| 和合 | 用户提出感情或亲密关系设定时可补人物的相处方式、信任、界限与表达。按明确需求选用，不作为一键默认内容。 |
| 彩石 | 非 MVU 文本状态栏。需要时生成字段模板、首条填写示例、展示 HTML/CSS 和匹配配置。 |
| 玄牝 / 谷神 / 众妙 | 分别设计变量与更新规则、生成阶段条件提示词、制作玩家状态栏。依据目标版本使用 [MVU](mvu.md) 和 [状态栏](status-bar.md) 参考。 |
| 言灵 | 用户单独要求写提示词时，明确用途、适用范围、上下文和预期行为，给出可放入目标字段的成稿。 |
| 试心 | 导出前核对已确认设定、人物动机、玩家行动权、NPC 自主性、关键词和开局时间线。去掉同义重复与机械化行为，保留人物的独立性和变化空间。 |

供身、供界、泥土和记言对应输入素材，祈愿对应用户最新任务。母语、英语和唤名按用户语言和客户端宏需求使用。原预设的叙事身份、模拟会话、思绪、预填、去思维链正则和旧标签格式只作为预设配置记录。角色卡中沿用用户希望的称呼、可见创作摘要和有效设定。
