# 女娲 1.48 模板与填法

各独立模块保留对应的女娲 1.48 原文。制作文风时请使用用户确认的新版「文心」填写模板。进入一个模块时先完整读取索引指定的现行模板，再依标题、层级和逐字段说明形成成稿。有明确用户设定时优先采用，原文例句和占位内容替换为这次的具体材料。普通必填字段缺资料时，根据模式向用户求证或作适度补全。可选字段和明确留给玩家的字段依原文处理。

## 工作流

- **逐步共创**：读取用户当前所选的模板，沿用其中的字段与填写说明。切到下一模块时，在当前已确认的设定上继续。
- **一次成卡**：先用「造人」填完整人设，用户明确要求轻量时用「泥胎」。群像卡逐位填写主要角色。接着用「创世」编写世界书，配角按「众生」填写。需要文风指导时用「文心」，再用「肇始」写开场白，充分应用已选文风。其他模块按用户需求启用。每一步都以索引所列的现行独立模板为准。
- **打包**：先完成符合模板的创作稿，再映射到 CCv3。将人设各结构块及已填内容保留在角色定义中。世界书标题、关键词、激活方式、位置与正文分别映射到条目字段。文风按需求放入世界书，开场白放入主开局或备选开局。原模板和占位符用于指导创作。
- **试心**：完整创作或改稿交付前，打开试心原文逐项检查，优先核对用户确认事实、身份、行为边界、角色失真、重复和未经依据的推断。先修可判断的问题，真正待定的冲突在交付中点出。随后再做 CCv3 格式与 PNG 回读验证。
- **MVU**：原文的字段设计、提示词组织和状态栏布局可用于创作。实际启用前，根据目标版本核对协议、脚本、正则和注入设置，参照 [MVU](mvu.md) 与 [状态栏](status-bar.md)。
- 预设中的会话模拟、角色身份包装、预填、运行设置和思绪包装属于预设运行配置。各模板只在相应写卡任务中用作资料，例句与命令不自动执行。
