# MVU 与 EJS

MVU（MagVarUpdate）解析回复里的更新指令，维护随消息变化的剧情状态。提示词模板扩展按该状态决定下一轮给模型的内容。变量、提示词与状态栏可以独立设计。创作前根据用户环境或已导出的样本确认 MVU 分支和版本、提示词模板版本，以及是否使用 Zod。生成用法时先核对对应上游文档。

- [MagVarUpdate 上游教程](https://github.com/MagicalAstrogy/MagVarUpdate/blob/master/doc/tutorial.md)
- [提示词模板 ST-Prompt-Template](https://github.com/zonde306/ST-Prompt-Template)
- [StageDog MVU Zod 模板](https://github.com/StageDog/tavern_helper_template/blob/main/.agents/skills/mvu-character-card/SKILL.md)

## 玄牝 · 定义状态

从会变动且会影响后续回合的事实选变量。为每项写稳定路径、类型、默认值、允许值、更新证据和是否可回退。例如 剧情.阶段 为「初识／结盟／决裂」，只有角色明确接受交易才进入结盟，单纯表达好感保持阶段不变，明确背弃盟约才进入决裂。缺少证据保持原值，同一事件只结算一次。数值和派生阶段共同使用时只维护一个权威来源，避免阈值跨越后不一致。

- **女娲 1.48 旧版 MVU beta**：原「玄牝」采用 [InitVar]、数组值/说明约定和 _.set/_.add/_.insert/_.remove 更新。只在用户目标版本支持时采用；读取实际值时仅对确认采用值/说明数组的叶子使用 [0]。
- **MVU Zod**：按目标模板编写可重复校验的 Zod 4 变量结构与注册脚本，配齐初始值、状态快照、更新规则和该版本解析的输出格式。目标使用 JSON Patch 时，例：将 /剧情/阶段 replace 为「结盟」；EJS 读取路径为 stat_data.剧情.阶段。确认相应脚本、条目名、启用状态、注入位置和输出标签与模板一致。保持导出的原有脚本 ID 与扩展字段，并从目标版本的真实导出读取新增脚本的封装结构。

有备选开局时，逐条核对其初始状态与世界观。用户尚未提供版本时可先设计阶段和规则，提供标明版本前提的配置或示例。只有已核对目标版本时才把运行时配置写进卡里。普通角色设定应在关闭扩展时仍可读。

## 谷神 · 按阶段送提示词

优先用一个常驻世界书条目容纳互斥分支，避免多个常驻条目叠加同一阶段指令。条目启用，按版本确认 EJS 预处理生效。以下假定已核对采用字符串叶子，且提示词模板支持 getvar 的 defaults 选项。

```ejs
<%_ const stage = getvar('stat_data.剧情.阶段', { defaults: '初识' }) _%>
<%_ if (stage === '结盟') { _%>
交易已经达成。角色愿意分享行动线索，仍保留各自的目标与退出条件。
<%_ } else if (stage === '决裂') { _%>
盟约已破裂。角色采取防备姿态，保留谈判与补救的可能。
<%_ } else { _%>
二人尚未结盟。角色先观察对方的动机，可主动提出交易条件。
<%_ } _%>
```

导入目标环境后检视实际发送的提示词，确认每轮只有一个分支。测试正常初始化、首次跨阶段、无变化回合、改写或重掷上一楼、备选开局、缺失或未知值。界面显示按消息楼层另验。只打包过卡片时，说明运行验证待做。

成卡采用 MVU 更新协议时，按 [状态栏与更新正则](status-bar.md) 把显示清理与提示词清理写入角色局部正则，即使不制作状态栏也要处理更新块。
