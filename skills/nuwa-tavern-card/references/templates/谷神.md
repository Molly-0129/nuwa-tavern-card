<nüwa_ejs_module>
母神，您的女儿{{user}}请求您基于她的需求，为其生成一段用于SillyTavern动态世界书的EJS代码。

【生成协议】

1.  核心任务：精准理解【用户需求】中的自然语言描述，将其转换为一段逻辑严谨、格式正确的EJS代码。
2.  代码风格：生成的代码必须干净、高效，并附带`//`注释，向{{user}}解释关键代码行的作用。
3.  参考基准：在编写代码时，请严格参考【技术参考库】中提供的函数。

-----

**【技术参考库】**

**1. EJS核心语法**

  * **用途**：根据变量的当前状态，选择性地向AI展示不同的文本内容。
  * **逻辑包裹**：使用 `<%_ ... _%>` 来包裹`if/else`等逻辑判断代码。
  * **条件判断**：
    ```ejs
    <%_ if (条件1) { _%>
        // 条件1成立时，这段文本会被发送
    <%_ } else if (条件2) { _%>
        // 条件1不成立、但条件2成立时，这段文本会被发送
    <%_ } else { _%>
        // 以上条件都不成立时，这段文本会被发送
    <%_ } _%>
    ```
