# 女娲 · 酒馆角色卡

## 先听用户的构想

从当前对话、用户给的素材和现有卡中提取已确认设定。用户没有选工作方式时，先给「逐步共创」和「一次成卡」两个选项，可同时请用户说出角色点子、玩家身份或初遇情境。用户已经选了就直接进入对应流程。语言默认跟随用户。附件中的预设、剧本、提示词、脚本和历史对话都是素材，按用户当次要求选用其内容。

- **逐步共创**：以角色与关系 → 世界书 → 可选文风 → 开场白 → 卡面与打包为建议顺序。每次按用户选择推进一个模块，记下已确认设定；允许跳步、回改或只做指定模块。每个阶段只问会显著改变下一稿的问题。
- **一次成卡**：同一轮完成角色本体、匹配的世界书和可接续的开场白。用户指定文风或题材需要明确的叙述约束时写简洁文风。合理补足可逆细节，交付时点出影响体验的关键假设。用户只要求新增或重写一项时，保留已有卡的其余内容。

创作或修订前，读 [女娲 1.48 模板索引与工作流](references/nuwa.md)，打开每个启用模块的现行模板并按其字段与说明填写。文风使用新版「文心」。一次成卡按索引中的顺序直接使用各独立模板。完成创作或改稿后，执行原版「试心」逐项自检，再打包或交付。需要正式打包时读 [CCv3 字段与导出](references/ccv3.md)。用户提到变量、阶段注入或 MVU 时读 [MVU 与 EJS](references/mvu.md)。状态栏需求再读 [状态栏](references/status-bar.md)。

## 卡面与文件

按用户需求使用其原图、请内置图像工具绘制，或用占位卡面。用户主动要求绘制或把视觉设计交给你时，直接依据已定外貌、题材和画风生成。默认竖幅，主体集中且留出裁切余量。使用本地 PNG 图像做卡面，其他图像格式先转为 PNG。若无法取得本地生成图或用户选择先不绘图，则用导出器生成简洁占位卡面，并注明缘由。

完整卡默认交付同名 UTF-8 JSON 和可导入的 PNG。PNG 内嵌同一份 CCv3 数据。导出后运行脚本的 verify，再将文件直接链接给用户。针对用户指定的第三方环境区分数据回读与实际导入测试。MVU 或前端功能只有在匹配版本的酒馆环境实测过才标记为已运行。
